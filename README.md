# okraPDF Desktop Downloads

Official public downloads for okraPDF on Mac. The app's source is maintained separately in a private repository.

## Mac installer

[Download okraPDF v1.0.0-rc.31 for Apple silicon](https://github.com/okrapdf/desktop-releases/releases/download/desktop-v1.0.0-rc.31/Okra-1.0.0-rc.31.dmg)

RC.31 gives the PDF more room: Activity starts hidden, document controls share one native toolbar, Find opens with Command-F, and markup uses a compact row of visible icons. In-place editing, automatic edit refresh, shared Undo/Redo and local automation through the bundled `okra` CLI remain available. Local OCR and model parsing remain explicit workflows; opening a PDF never starts a parse.

The application and installer are Developer ID signed and Apple notarized. This prerelease requires macOS 13 or later on Apple silicon. Full Preview parity remains in progress.
